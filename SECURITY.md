# Security and data boundaries

This is an early local research alpha, not production-hardened SaaS.

- Studio and generated apps bind to `127.0.0.1`, check Host, and require a random per-process request token for mutations. Origin checks protect browser writes. There is no user authentication, TLS or multi-tenant isolation. Do not proxy these servers onto a public interface.
- Local users/processes that can read the app can obtain its token; the token is a browser cross-origin defense, not an access-control boundary against local code.
- Branch has no external adapters and never sends notifications. It models only declared business rules. A Branch object is not a code sandbox or tamper-proof ledger.
- Teachpack defaults to simulation-only execution. Live adapters require explicit authorization, but must separately validate arguments and enforce access controls. Retries only deduplicate when the adapter honors the generated idempotency keys.
- Teachpack visual capture starts only after a user selects a screen or window. Images and OCR text are processed locally and stored under `.local/`, not sent to an external OCR or model provider. A chosen screen may contain credentials or personal data, so share a limited window where possible and treat local captures as sensitive. The guide detects text checkpoints; it cannot prove that an underlying business action succeeded.
- Optional Teachpack click detection requires a separate checkbox and macOS Input Monitoring permission. It runs only during recording, on a full display with one active display. Click time and normalized position are stored locally; no keystrokes are requested or recorded. The listener can see clicks outside the intended workflow on that display, so review or discard recordings before export.
- La détection facultative des clics Teachpack exige une case à cocher distincte et l’autorisation macOS « Surveillance des entrées ». Elle fonctionne seulement pendant l’enregistrement d’un écran entier avec un seul écran actif. L’instant et la position des clics restent en local ; aucune frappe clavier n’est demandée ou enregistrée. Le capteur peut voir des clics hors de la procédure sur cet écran : vérifiez ou écartez l’enregistrement avant l’export.
- La detección opcional de clics de Teachpack requiere una casilla aparte y el permiso de Supervisión de entrada de macOS. Solo funciona durante la grabación de una pantalla completa con una única pantalla activa. El momento y la posición de los clics se guardan localmente; no se solicitan ni registran teclas. El sensor puede ver clics ajenos al procedimiento en esa pantalla: revisa o descarta la grabación antes de exportarla.
- Checkout performs actual browser interactions and quote submissions. Run only against an authorized sandbox. HTTP-origin filtering is not a complete malicious-site isolation boundary. The optional model driver sends page observations and task details to the configured provider; use synthetic inputs and no secrets in page content.
- Exit keeps source exports, notes and attachment content on disk. Extra fields are preserved in the source archive even when no active destination behavior exists. Never publish exported artifacts containing personal or confidential information. The migration manifest is not a signed attestation.
- `.env`, `.local/`, `output/`, `node_modules/` and tarballs are excluded from Git. Package allowlists exclude studio state and generated artifacts. Never put credentials into fixtures, examples or logs.

To report a vulnerability privately, use [GitHub's private vulnerability reporting](https://github.com/gbesse/frontier-lab/security/advisories/new). Do not attach real customer exports or keys to public issues. This research alpha does not establish a security response SLA.
